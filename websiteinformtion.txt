                   Portuguese Restaurant Management System
================================================================================

PROJECT NAME : Aman-Bhaiya-Restaurent (Portuguese Restaurant Management System)
PROJECT TYPE : Full-stack Web Application
RESTAURANTS  : 2 (Original's Casa de Peixe + Lapicanha)
LOCATION     : Setúbal, Portugal


================================================================================
                              PROJECT OVERVIEW
================================================================================

This is a full-stack web application for managing two Portuguese restaurants -
"Original's Casa de Peixe" (seafood) and "Lapicanha" (grilled meats). The system
provides a public-facing website with restaurant information, menus, photo
galleries, and reservation capabilities, along with administrative features for
content management.

The application showcases authentic Portuguese cuisine with a focus on:
- Casa de Peixe: Traditional Portuguese coastal/seafood cuisine
- Lapicanha: Premium grilled meats (specializing in picanha)


================================================================================
                              TECH STACK
================================================================================

FRONTEND:
- Framework      : React 18 with TypeScript
- Routing        : Wouter (client-side routing)
- State Mgmt     : TanStack Query (React Query) for server state
- UI Components  : Shadcn/ui component library with Radix UI primitives
- Styling        : Tailwind CSS (custom Portuguese theme: wine, beige, olive)
- Typography     : Playfair Display (serif), Inter (sans-serif), Geist Mono
- Forms          : React Hook Form with Zod validation
- Build Tool     : Vite
- i18n           : Language Context with translations.ts

BACKEND:
- Framework      : Express.js with TypeScript
- API Design     : RESTful API
- File Uploads   : Multer middleware (image uploads)
- Storage        : Interface-based storage system (MemStorage for dev)
- Logging        : Custom middleware for API request logging
- Error Handling : Centralized error handling middleware

DATABASE:
- ORM            : Drizzle ORM
- Dialect        : PostgreSQL
- Provider       : Neon Database (serverless PostgreSQL)
- Migrations     : Drizzle Kit
- Tables         : restaurants, menu_items, reservations, gallery_photos

DEPLOYMENT:
- Vercel (serverless via api/index.ts)
- vercel.json configuration
- Environment var: DATABASE_URL (PostgreSQL connection)

INTEGRATIONS:
- Google Maps (requires VITE_GOOGLE_MAPS_API_KEY)

================================================================================
                           DATABASE SCHEMA
================================================================================

TABLE: restaurants
------------------
- id           : varchar (UUID, PK)
- name         : text (required)
- slug         : text (required, unique)
- description  : text (required)
- address      : text (required)
- phone        : text (required)
- email        : text (required)
- hours        : text (required)
- createdAt    : timestamp

TABLE: menu_items
-----------------
- id           : varchar (UUID, PK)
- restaurantId : text (FK)
- name         : text (required)
- description  : text (optional)
- price        : text (required)
- category     : text (starters | mains | desserts | drinks)
- imageUrl     : text (optional)
- createdAt    : timestamp

TABLE: reservations
-------------------
- id              : varchar (UUID, PK)
- restaurantId    : text (FK)
- name            : text (required)
- email           : text (required)
- date            : text (required)
- time            : text (required)
- guests          : integer (required)
- specialRequests : text (optional)
- status          : text (default: "pending")
- createdAt       : timestamp

TABLE: gallery_photos
---------------------
- id           : varchar (UUID, PK)
- restaurantId : text (FK)
- imageUrl     : text (required)
- title        : text (optional)
- description  : text (optional)
- createdAt    : timestamp
